# Agent Studio MVP Demo — PRD V1.3

依据用户指定的《统一Agent基建平台_PRD方案_V1.3.docx》修改。原 PRD 未改动。所有结果、指标、耗时和服务调用为确定性模拟，不能代替真实业务质量及容量验收。

## 已更新

- 三种构建入口：简单配置、空白/模板基础编排、受控服务接入。
- 自由拖动节点、端口拖线或点选连接、箭头连线、异常虚线、滚轮缩放、画布平移与适应视图。布局自动保存，连线改动需保存草稿。
- 原子节点、变量映射、条件分支、异常出口、静态检查、单节点与完整调试。
- 在线/批量、会话、审批、灰度独立配置。
- 不可变版本保存完整配置及知识、政策、工具、模板、Skill 依赖。
- 业务编辑者、指定审批人、发布者角色分离。
- 批任务失败重试、幂等去重、政策失效暂停；生产会话版本绑定。
- 本机 localStorage 自动保存，重置需确认。
- 应用创建必选责任人，工作台支持重命名和删除，并清理关联运行、批任务与评测记录。
- 配置与流程页提供草稿 / 历史固化版本切换，历史配置复制后形成新草稿，版本快照保持不可变。
- 评测页支持本地登记 JSONL/CSV/JSON 数据集版本，每次评测生成任务记录并绑定应用责任人、Agent 版本和数据集。

## 评审路径

A：改检索策略或节点 → 保存 → 静态检查 → 正常/无结果调试 → 固化 → 评测 → 切发布者 → 灰度 → 运行记录 → 回退。

B：policy@2 草稿固化 → 评测失败 → 开启变体联系方式识别 → 保存并固化新版本 → 重评 → 申请审批 → 指定审批人通过 → 发布者上线 → 批任务重试与重复提交去重。

C：简单配置转流程 → 添加物流分支 → 超时转人工 → 绑定 kb@2 → 固化回归发布 → 多轮生产会话 → 回退后旧会话保持原版本、新会话使用恢复版本。

通用：空白应用建图、共享模板、显式 Skill 版本升级、版本化服务契约注册与模拟调用。

## 运行

执行 `node serve.cjs`，打开 http://127.0.0.1:4173/#list 。

GitHub Pages 使用仓库根目录的 `index.html`；根目录静态文件由 `dist/` 同步生成，推送到 `main` 后可直接访问 `https://gjr-xiaoyi.github.io/agent-studio-demo/`。

执行 `node verify.cjs` 检查状态规则与 UI 渲染；支持单独执行 `node verify-v13.cjs` 与 `node verify-ui.cjs`。

## 边界

支持自由拖动节点、端口拖线、可视化连线、缩放和平移；不实现循环、并行、子流程、多 Agent、自主 Skill 调度、自动放量或任意代码托管。外部服务仅观察接口边界和 externalTraceId。

当前交付本地预览与可迁移页面包，未生成 redcowork 链接。旧页面脚本备份于 baseline-v1，不在新版页面中加载。
